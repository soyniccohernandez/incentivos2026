# 🚀 Incentivos Actores 2026

Sistema de gestión de incentivos desarrollado con **Laravel**. Este proyecto está diseñado para automatizar y administrar los procesos de asignación de incentivos para el año 2026.

## 🛠️ Tecnologías utilizadas
* **Framework:** Laravel 11+
* **Lenguaje:** PHP 8.2+
* **Base de Datos:** MySQL / PostgreSQL (según config)
* **Frontend:** Blade / Tailwind CSS / Livewire (opcional)
